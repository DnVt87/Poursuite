Explicação de zero resultados (aparece quando a consulta retorna 0)

Por que zero?

O sistema reexecutou cada cláusula isolada contra a carteira. Resultado:

  • class_type = "Execução de Título Extrajudicial" → 312 processos
  • value >= 100000 → 198 processos
  • movimento_any (penhora OR SISBAJUD/bloqueio) → 0 ← cláusula que zerou tudo

A cláusula de movimentação não bate com nenhum processo desta carteira. Possíveis causas: termos com acentuação diferente, FTS5 tokenizer não removendo diacríticos, ou o evento simplesmente não está nesta carteira.
